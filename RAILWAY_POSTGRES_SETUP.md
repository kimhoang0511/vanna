## 🚀 Setup Steps

### Bước 1: Add PostgreSQL Database

1. **Mở Railway Dashboard**: https://railway.app/dashboard

2. **Chọn project**: `vanna-production`

3. **Add PostgreSQL**:
   - Click nút **"+ New"** (góc trên phải)
   - Chọn **"Database"**
   - Chọn **"Add PostgreSQL"**
   
4. **Đợi provisioning** (~30 giây):
   - Railway sẽ tự động tạo PostgreSQL instance
   - Tự động set các environment variables

### Bước 2: Verify PostgreSQL Variables

Click vào **PostgreSQL service** → Tab **"Variables"**

Phải có các biến này (Railway tự động set):
```bash
DATABASE_URL="postgresql://..."
PGDATA="/var/lib/postgresql/data/pgdata"
PGDATABASE="railway"
PGHOST="<internal-domain>.railway.internal"  # Private domain
PGPASSWORD="<auto-generated>"
PGPORT="5432"
PGUSER="postgres"
POSTGRES_DB="railway"
POSTGRES_PASSWORD="<same-as-PGPASSWORD>"
POSTGRES_USER="postgres"
RAILWAY_PRIVATE_DOMAIN="<internal-domain>.railway.internal"
```

**Quan trọng**: `RAILWAY_PRIVATE_DOMAIN` được dùng cho kết nối nội bộ (nhanh hơn public domain)

### Bước 3: Config Main Service

Click vào **Main Service** (Vanna app) → Tab **"Variables"**

**Thêm biến này:**
```bash
CACHE_BACKEND=postgres
```

**Cách thêm:**
1. Click "New Variable"
2. Variable name: `CACHE_BACKEND`
3. Value: `postgres`
4. Click "Add"

**KHÔNG CẦN thêm các biến PGHOST, PGUSER, etc.** vì Railway tự động share giữa các services!

### Bước 4: Redeploy

Railway sẽ **tự động redeploy** sau khi bạn thêm variable.

Hoặc manual:
1. Click vào Main Service
2. Tab "Deployments"
3. Click "Deploy" → "Redeploy"

Đợi ~2-3 phút để deployment hoàn thành.

### Bước 5: Verify Deployment

1. **Check deployment status**:
   - Tab "Deployments" → Status phải là "Success" (màu xanh)

2. **Check logs**:
   - Tab "Logs" (hoặc click vào deployment)
   - Tìm các dòng này:
   ```
   ✅ PostgreSQL cache initialized
   ✅ Connection pool created: 1-10 connections
   ✅ PostgreSQL cache table ready
   ```

3. **Test connection**:
   ```bash
   python3 test_railway_postgres_connection.py
   ```

## 🔍 Railway Variables Explained

### PostgreSQL Service Variables (Tự động)
```bash
RAILWAY_PRIVATE_DOMAIN   # Internal domain for service-to-service
PGHOST                   # Public PostgreSQL host
PGDATABASE               # Database name (default: "railway")
PGUSER                   # Username (default: "postgres")
PGPASSWORD               # Auto-generated strong password
PGPORT                   # Port (default: 5432)
```

### Main Service Variables (Cần thêm)
```bash
CACHE_BACKEND=postgres   # Enable PostgreSQL cache
```

### Connection Priority (Code xử lý tự động)
```
1. RAILWAY_PRIVATE_DOMAIN (fastest - internal network)
2. PGHOST                 (fallback - public host)
3. DB_HOST                (custom override)
4. localhost              (local development)
```

## 🐛 Troubleshooting

### Error: "connection pool exhausted"

**Nguyên nhân:**
- PostgreSQL service chưa được add
- CACHE_BACKEND=postgres chưa được set
- Deployment chưa connect được tới PostgreSQL

**Fix:**
1. Verify PostgreSQL service exists in Railway
2. Verify CACHE_BACKEND=postgres in Main service variables
3. Check logs: `railway logs`
4. Redeploy nếu cần

### Error: "relation 'vanna_cache' does not exist"

**Nguyên nhân:**
- Database table chưa được tạo
- Code chưa chạy `_create_table_if_not_exists()`

**Fix:**
1. Check logs để xem table creation
2. Manually create table:
   ```sql
   CREATE TABLE vanna_cache (
       id VARCHAR(255) PRIMARY KEY,
       data JSONB NOT NULL,
       created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
       updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
   );
   ```

### Cache không hoạt động (cached=False)

**Debug steps:**
1. Check cache stats:
   ```bash
   curl "https://your-app.railway.app/api/v0/cache_stats" \
     -H "X-API-Key: YOUR_KEY"
   ```

2. Check logs cho errors:
   ```bash
   railway logs --follow
   ```

3. Verify CACHE_BACKEND:
   ```bash
   railway variables
   ```

4. Test database connection:
   ```bash
   railway run psql $DATABASE_URL -c "SELECT COUNT(*) FROM vanna_cache;"
   ```

## 📊 Database Queries

### Connect to PostgreSQL
```bash
railway run psql $DATABASE_URL
```

### Useful Queries
```sql
-- View all cached questions
SELECT 
    id, 
    data->>'question' as question,
    created_at,
    updated_at
FROM vanna_cache 
ORDER BY created_at DESC;

-- Count cache entries
SELECT COUNT(*) FROM vanna_cache;

-- View specific question cache
SELECT * FROM vanna_cache 
WHERE data->>'question' LIKE '%customer%';

-- Clear all cache
DELETE FROM vanna_cache;

-- View cache with SQL
SELECT 
    id,
    data->>'question' as question,
    data->>'sql' as sql
FROM vanna_cache
LIMIT 10;
```
